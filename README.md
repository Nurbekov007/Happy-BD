# Birthday Site 💕

## Как залить на GitHub Pages:

1. Зайди на **github.com** → создай новый репозиторий (например `birthday`)
2. Загрузи **ВСЕ файлы** из этой папки:
   - index.html
   - photo1.jpg ... photo8.jpg
   - video6.mp4
   - music.mp3
3. Зайди в **Settings → Pages**
4. Source: **Deploy from a branch** → ветка `main` → папка `/ (root)`
5. Нажми Save
6. Через 1-2 минуты сайт будет на: `https://ТВО_ЛОГИН.github.io/birthday/`

Готово! ❤️
